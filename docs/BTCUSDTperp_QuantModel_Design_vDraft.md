> 전략을 특정하지 않는(무가정) 컨셉의 BTCUSDT Perpetual 퀀트 모델을 처음부터 함께 설계한 세션.

## 1. 출발 컨셉과 학습 패러다임

**핵심 인식:** "전략을 특정하지 않는다"는 전략 가정을 없애는 게 아니라, 그 가정을 **목적함수(라벨·보상)로 옮기는 것.** 무엇이 좋은 결과인가를 어딘가에서 반드시 정의해야 하고, 그 정의가 곧 모델의 숨은 전략이 된다.

**학습 패러다임 스펙트럼:**
- **지도학습(예측):** f: 피처→라벨. 출력이 미래를 안 바꿈(피드백 루프 없음). 예측→행동 변환 룰 별도 필요. 표본 효율 좋고 진단 가능.
- **강화학습(정책):** π: 상태→행동. 행동이 궤적을 바꿈(경로의존). 라벨 없이 보상 최적화. 사이즈 출력에 자연스럽지만 난이도 최고.
- **미분가능 직접 정책최적화:** 중간항. 최적화 기계장치는 지도학습, 문제 정의(라벨 없음·행동 출력·손익 목적·경로의존)는 강화학습.

**결정:** 지도학습으로 엣지 정찰 → 확인 후 정책 정교화. 지도학습은 "최종 모델"이 아니라 "엣지 존재 여부 정찰"로 사용.

**캔들 온리의 정보 상한:** OHLCV는 가장 경쟁 소멸된 피처 공간. 방향 예측 엣지는 얇고, 현실적 엣지는 "방향 적중"보다 **변동성·레짐 타이밍과 사이징**에서 나올 가능성. 집 전체를 방향 예측 위에 올리지 않는다.

## 2. 관통 철학 (전 층 공통)

- **무가정:** 검증 안 된 직관으로 사전 확정하지 않음. 데이터가 정함. (timeframe·배리어 지표·피처·창 모두 탐색축)
- **인과성:** 모든 계산은 그 시점까지 정보만. 구현 시 **봉 마감 기준 엄수**.
- **장식 금지:** 모든 부품은 예측력을 실제 개선할 때만 생존. 아니면 탈락·재검증.
- **팻테일 대응:** robust KF(방어) + semi-deviation(측정)으로 일관.
- **불확실성 관통:** KF 공분산 → 입력 → 2층(softmax·분위수) → 3층 사이징.
- **엣지 정찰 우선:** 지도학습으로 엣지 확인 후에만 정책 정교화.

## 3. 검증 프로토콜

**walk-forward (학습셋 + 검증셋, 홀드아웃 없음)**
- 창을 시간순으로 밀며 "과거 학습 → 바로 뒤 미래 검증" 반복. 정적 3분할보다 데이터 효율적, 여러 국면 통과.
- **홀드아웃 없음:** 짧은 홀드아웃은 국면에 휘둘리는 노이즈라 없느니만 못함. 대신 **비교 개수**로 부풀림 관리(다중비교 방어를 홀드아웃이 아닌 개수 제한으로 대체).
- **배포 모델:** 검증된 파이프라인으로 전 데이터 재학습. (분할은 방법론 검증 절차지 배포 모델 생성 절차가 아님)

**세 종류의 검증 구분 (핵심):**
- **후보1 라벨 분포 검증** (성과 안 봄) — 배리어 파라미터·지표 선별용
- **후보2 예측 정확도 검증** (성과 아님, 예측력) — **피처·모델 선별용**
- **후보3 경제적 성과 검증** — **선별 아닌 최종 확인용**

> **선별에 성과(후보3)를 쓰면 과적합.** 선별은 예측력·라벨분포로, 성과는 오직 최종 확인.

**국면 간 walk-forward:**
- 표준 walk-forward는 검증 구간 국면을 우연에 맡김 → 국면 의존성을 못 봄
- **방식1:** 검증을 학습과 **다른 국면**에 일부러 걸침(강건성 시험) — 예: 불장 학습 → 베어 검증
- **방식2:** 국면별 성적 **분리 집계**(어느 국면에서 엣지 살고 죽나 진단)
- 라벨 판정의 층3(국면 일관성)과 같은 정신

**timeframe 탐색:** 15m/1h/4h/1d 단독 + 조합 전수 탐색, 검증 최고 채택. "성공/실패" 이분법이 아니라 **"어느 축을 바꿔야 할지 알려주는 진단"**으로 읽음.

## 4. 라벨 설계 (Triple-Barrier)

**뼈대:** 진입 후 상단 배리어(+x·변동성) 먼저 치나, 하단(−x) 먼저 치나, 시간 만료냐.
- 단순 "N봉 후 수익률"과 달리 **실제 청산 경로** 반영.
- **시간 한계(수직 배리어):** 가격이 영영 안 닿는 경우를 유한하게 처리하기 위함. 도달시간 예측을 위해서가 아니라 라벨을 유한하게 정의하기 위해 필요.

**배리어 폭 설계:**

*대전제 — 시점 인과성:* 배리어 폭은 그 진입 시점까지의 정보로만 계산. 미래 변동성으로 폭을 그으면 정답(라벨)에 미래가 새어(정보누수) 백테스트만 좋고 실전은 무너짐. **누수 여부는 지표 종류가 아니라 "그 시점 정보만 썼나"로 갈림** (그 시점까지 데이터로 낸 GARCH 예측값은 누수 아님).

*지표 후보 (탐색축, 확정 보류):*
- **ATR** — 갭 내성(True Range), 가격 단위 직결, 실행 정합, 관습적 견고. 통계 효율은 낮은 편.
- **Yang-Zhang (YZ)** — OHLC 최대 활용, 갭·추세 편향에 강함, 통계 효율 최고. (밤샘 갭 + 개장 + Rogers-Satchell 항 구성이 크립토 갭·추세에 정합)
- 둘 다 유지, 검증이 정할 독립 탐색축. 상호배타 아님(폭=YZ, 실행=ATR 역할 분담 가능).
- **탈락:** GARCH 등 예측형 → 배리어 폭에선 편익(한계적 미래지향) 작고 부담 큼. **2층 예측 입력으로 이관.**

*파라미터 (서로 얽힘):*
- **창 길이** (변동성 측정 구간), **배수 x** (폭=x·변동성), **시간 한계 N**
- **x·N 강결합:** 넓은 폭엔 긴 N, 좁은 폭엔 짧은 N. 비율 어긋나면 라벨이 한쪽(전부 만료/전부 방향)으로 붕괴.
- **대칭으로 시작** (비대칭은 "하락이 급하다"는 사람 편향 주입이라 후순위)

*정하는 법 — 접근 B (라벨 분포 역산):*
- 성과로 튜닝하면 라벨을 성과에 맞춰 조작하는 과적합 → **성과 일절 안 봄**
- 대신 "건강한 라벨 분포"를 만족하는 창·x·N 역산

*건강한 라벨 분포 판정 틀:*
- **층1 (학습 가능성 필터, 통과/탈락):** 방향(상단+하단) vs 만료가 어느 쪽도 극단(대략 80%대 후반↑) 아니고, 소수 클래스가 각 학습 창에서 최소 절대수 확보. **정밀 경계는 의도적으로 안 정함** — 명백한 극단만 쳐내는 느슨한 문턱.
- **층2 폐기:** 상하 대칭성(시장 대칭 가정=사람 편향), 방향 노이즈 지속성(전략 편향+새 파라미터), 도달시간 형태(층1과 중복). "라벨이 의미 있나"의 판정은 우리가 미리 하지 않고 2층·검증에 맡김.
- **층3 (강건성 선택):** 국면 간 일관성만. 같은 파라미터가 불장·베어·횡보 넘나들며 층1 유지하나. (파라미터 민감도는 국면 일관성에 흡수)

## 5. 타깃 구성과 멀티태스크

**타깃 (변동성 타깃은 복잡성 원인이라 제거):**
- **타깃1 배리어 결과** (방향·크기 결합, 3-클래스 분류) — 핵심. 방향과 크기가 한 배리어 사건에 결합.
- **타깃2 도달시간** (회귀, 청산용) — 보조. **모델이 예측한 값**이어야 청산에 쓸 수 있음(과거 기록=메타데이터로는 청산 불가).
- 만료 처리: 도달시간 회귀에서 **버리지 않고 절단(censored) 정보로 살림** (초기 N봉 클리핑 → 값하면 생존분석 격상). 배리어 결과 분류에선 만료가 정식 클래스.

**독립 2개 모델 탈락:** 도달시간은 "어느 배리어에 언제"라 배리어 결과에 **조건부**. 배리어 결과 없이 도달시간만 예측하면 무의미. → 둘을 묶어야 함.

**멀티태스크로 확정:**
- 두 타깃이 **같은 배리어 사건의 두 투영**이라 깊이 결합
- **손실 가중 λ:** 총손실 = 배리어결과손실 + λ·도달시간손실. 공유트렁크라 두 손실을 합쳐야 학습 방향이 정해짐.
- **λ가 배리어 결과 중요도를 양방향으로 흔드는 이유 = 트렁크 공유:**
  - 경쟁(해로움): 트렁크 용량을 도달시간과 나눠 씀 → 큰 λ면 배리어 결과 몫 줄어듦
  - 협력(이로움): 관련 태스크라 도달시간이 "속도·강도" 표현을 유도 → 배리어 결과에도 좋은 표현
  - λ 조절로 균형. **도달시간 보조로 낮게 시작**(협력만 얻고 경쟁 피함).

## 6. 학습 모델 (MLP)

**멀티태스크 구현 후보 검토:** 공유트렁크 NN / 멀티아웃풋 트리(이종 타깃 어색) / 약한 결합(트리+예측 교환) / 계층적 조건부 / 선형(표현력 부족).

**NN 확정 근거:**
- 이종 타깃(분류+회귀)을 한 틀에서 native
- **협력 효과가 가장 깊음** (공유트렁크가 진짜 공유 표현 학습 — 트리는 이 핵심 이점을 못 살림)
- **3층 웜스타트 이식 가능** (신경망이어야)
- 대가: 표본 배고픔(레짐 희소에 불리) → 트리 벤치마크 + 정규화로 방어

**"레짐 희소" 정밀화 (중요):**
- **국소 패턴 인스턴스 = 수백~수천 개** (풍부 — 1h/4h면 표본 충분, 과적합 공포 과하게 걸 필요 없음)
- **엣지의 독립 검증 단위 = 매크로 국면 6~8개** (희소 — timeframe 바꿔도 안 늘어남)
- 두 숫자가 다름: "패턴 배우는 표본"은 많고 "패턴 일반화 검증 표본"은 적음
- 과적합 리스크는 timeframe마다 다름(1h 낮음, 1d 높음). 방어는 "일률적 강한 정규화"가 아니라 **국면 간 walk-forward 검증**에 무게.

**구조 — 공유트렁크 멀티태스크 MLP:**
- **입력: 벡터** (1층이 시간 압축하니 시퀀스 불필요·중복. CNN/RNN은 시퀀스 필요, Transformer는 레짐 희소에 배고픔)
  - 벡터 입력 NN에서 MLP는 "여러 후보 중 최적"이 아니라 **그 형태의 필연적 귀결** (CNN=지역성, RNN=순서, Transformer=토큰집합 필요 → 벡터엔 안 맞음)
- **헤드 분기:** 늦게 분기(트렁크 넉넉히 공유 → 협력 살림). 간섭 시 앞당김.
- **불확실성 출력:** 배리어 결과 softmax(확률 native) + 도달시간 분위수 회귀(pinball loss)
- **깊이·너비:** 얕고 좁게 시작 (신호처리층이 추상화 선점 + 파라미터 억제로 국면 암기 방지). 깊이=조합의 층수(추상화 단계), 너비=각 층 감지기 수.
- **정규화:** 표준 3종(드롭아웃·가중치감쇠·조기종료), **강도는 timeframe·표본 따라 검증이 조절** (일률적 강한 정규화는 과함 — 과소적합 위험)

**트리 벤치마크:** 배리어 결과 단일태스크 트리를 하한선으로. NN이 넘어야 정당. 정규화 강도의 나침반.

## 7. 1층 신호처리층

*원시 캔들을 인과적으로 정제해 피처 생산. 시간 구조를 피처로 압축(→2층이 MLP·벡터로 단순해지는 근거).*

**KF 구체화:**
- **상태 모델: 선형** (level+slope 로컬 선형추세). 비선형 미도입 → **EKF/UKF 불필요** (비선형 상태 도입할 때만 정당)
- **Robust 채택 (Student-t 측정노이즈):**
  - Gaussian은 꼬리가 얇아 거대 점프를 "노이즈로 불가능 → 진짜 신호"로 오인, slope가 급변에 과잉 반응·오염
  - Student-t는 "팻테일 노이즈일 수 있다"고 인정해 반응을 눅임
  - 동작: 거대 점프에 **한 번은 신중(낮게 가중), 지속되면 추종** → 일시적 스파이크는 거르고 진짜 전환은 시차 두고 따라감. "무조건 이상치 제거"가 아닌 지속성 기반 판단
  - "거대 점프가 가끔 나옴" 자체가 팻테일 증거(Gaussian이면 거의 안 나와야 함)
- **IMM 보류 (단일 KF 시작):** 계열2(레짐)를 ER·Hurst가 이미 커버 → 중복. 복잡도·과적합 대가 큼. 검증이 필요하다 하면 격상.
- **Q·R·자유도:** 학습 창에서만 MLE 또는 소수 그리드 (인과성). 명시적 창보다 KF에 자연스러움.

**창 길이:**
- **완전 독립** — 그룹화 비율 가정은 "틀리면 접근을 물려야 하는 진짜 가정"(조절로 못 빠져나옴)이라 회피
- **순차 탐색** (coordinate descent): 한 피처씩 최적화. 곱(15,600) → 합(30~60판). 조합 하나 = walk-forward 한 판.
- 대가(피처 간 상호작용 누락)는 **피처를 독립 정보로 중복 제거**했기에 완화 → 순차 탐색 정당화
- KF는 창 그룹서 예외, Q/R로 독립 튜닝

**정상성 변환:**
- 피처 상대량화: 카탈로그가 이미 대부분 상대량 (선제 해결)
- z-score: 넣되 **train 구간 통계로만** (인과성, walk-forward 각 창)
- 분수차분: 원시 가격을 피처로 안 쓰니 불필요 (가공물은 이미 정상)

**신호처리 부품 채택:**
- 웨이블릿: 멀티타임프레임과 중복 → 기본 제외
- EMD/EEMD: 비인과(미래 누수) → 제외
- 추가 부품 없음

## 8. 예측 입력 (피처)

*1층 피처를 벡터로 묶어 2층 MLP에 공급. 중복 제거된 최소 골격, 예측력 검증이 최종 선별.*

**핵심 골격 (6축):**
| 계열 | 피처 | 역할 |
|---|---|---|
| 1 추세 | **KF slope + 불확실성** | 방향·강도 (불확실성은 사이징 사슬 연결) |
| 2 레짐/추세강도 | **ER + Hurst** | ER=추세/노이즈 비율, Hurst=추세추종/평균회귀 (보완) |
| 3 변동성 | **변화(수축팽창)** | 수준은 배리어 폭과 되풀이라 제외, 변화만 |
| 4 거래량 | **상대거래량** | "움직임의 신뢰도" 독립 축. 크립토 신뢰성 이슈로 문턱 높게 |
| 5 분포모먼트 | **semi-deviation** | 팻테일 측정(꼬리위험 크기). KF(제거)와 상보 |
| 6 캔들형태 | 종가위치 | 최하 우선순위 |

**조건부 후보:** kurtosis(꼬리 두께 별도 정보), 가격-거래량 관계, 짧은 래그, 종가위치. (skew는 semi-dev와 중복이라 제거)

**KF와 계열5의 상보성 (둘 다 쓰는 이유):**
- KF = 팻테일 **제거**한 깨끗한 추세 / 계열5 = 제거된 팻테일의 **크기** 측정 → 정확히 반대 정보, 안 겹침
- 대체 불가(각자 다른 산출물: 추세 vs 꼬리위험), 병렬 작동(순차 아님)

**되풀이(정보누수) 방지:**
- 배리어를 만든 변동성 수준을 입력으로 주면 모델이 정답을 역산 → 예측력 부풀림
- **변동성 수준은 입력서 제외, 변화(수축팽창)만** (배리어가 안 쓰는 독립 정보)
- semi-deviation은 배리어와 약한 상관 → 검증에서 만료 예측력 모니터

**래그:** **현재값만(래그 0) 시작** (1층이 시간 압축). 부족하면 짧은 래그(1~2봉)·변화율만. 많은 래그 필요 = 시퀀스 모델 신호라 재고.

## 9. 멀티타임프레임 결합

*하위 결정 timeframe에 상위 timeframe 맥락을 붙임 (timeframe 전수 탐색의 "조합" 버전).*

- **무엇을:** 상위(4h·1d)에선 **추세(KF slope) + 레짐(ER)** 만 좁게 (컨텍스트 목적). 검증이 최종 판정.
- **어떻게 (핵심 난제):** **완성된 상위 봉만 forward-fill.** 진행 중인 상위 봉을 쓰면 미래 누수(가짜 엣지 1순위 원천). 결합은 벡터 이어붙이기(단순).
- **어느 상위:** 1~2개 제한 (과적합·조합 관리)
- **창 전역 정합 해결:** 상위 봉 자체가 "긴 창" 역할 → 하위에서 긴 창 고민을 timeframe 계층이 자연 정리
- **필요성:** 멀티타임프레임 자체가 검증 대상 (단독 vs 조합 중 예측력 나은 쪽). 당연히 넣는 게 아님.

> ⚠️ 구현 시 "완성된 봉만" 규율 특히 주의 — 백테스트가 예쁘게 나오면 진행 중 봉 누수 의심.

## 10. 3층 결정층

**멍청한 버전 (엣지 정찰용, 확정):**
- **방향:** p_up vs p_down
- **진입:** max(p_up, p_down) > θ (고정 임계값), 아니면 관망. 만료 확률 높으면 자연히 진입 억제.
- **사이즈: 고정 1단위 (사이징 배제)** — 방향 예측만으로 비용 넘겨 돈이 되나 순수 정찰. 사이징 효과와 방향 엣지를 분리.
- **청산:** 배리어 도달 또는 시간한계 (라벨 정의 그대로 실행 → 라벨-실행 정합). 도달시간 예측은 멍청한 버전에선 미사용.
- **비용:** 수수료(테이커 ~0.05%)·펀딩(데이터 있으면 실제, 없으면 보수적 상수)·슬리피지(고정 bps 또는 변동성 비례) 차감해 손익 산출.
- **튜닝 최소:** θ만, 그것도 안정성만 보지 최적화 안 함.

> **왜 멍청해야 하나:** 정교한 룰로 손익을 짜내면 검증셋에 과적합돼 "예측 엣지"와 "룰 튜닝"이 안 갈림. 예측이 진짜 좋으면 멍청한 룰로도 나와야 함. 정교한 룰로 겨우 살아나는 엣지는 신뢰 불가.

**최종 버전 (열린 자리):**
- 형태 **미정** — 후보: 얇은 룰+사이징 / 고전 사이징(Kelly류) / 미분가능 직접 정책최적화 / 풀 RL / 조합
- **2층 엣지 확인 후** 엣지 성격(방향 강도·도달시간 정확도·경로의존·비용 민감도)에 맞춰 결정
- 직접 정책최적화는 유력 후보이나 확정 아님
- **인터페이스·웜스타트 경로는 형태 무관하게 확보됨** (2층이 softmax·분위수·KF 불확실성 다 내놓음, MLP라 이식 가능)

## 11. 엣지 판정 관문

**관문1 — 통계적 엣지 (3층 불요):**
- 2층 예측력이 기준선(무작위·순진모델·트리 벤치마크) 넘나
- 지표: 균형정확도·MCC·로그손실 (적중률 아님 — 클래스 불균형 보정)
- **못 넘으면 즉시 폐기** (예측이 동전던지기면 그 위에 뭘 얹어도 소용없음)

**관문2 — 경제적 엣지 (멍청한 3층 필요):**
- 예측 정확 ≠ 돈 (맞히는 게 작은 움직임·틀리는 게 큰 움직임이면 손해, 비용이 엣지를 먹음)
- 예측을 포지션으로 변환해야 손익이 나옴 → 그 변환이 3층
- 판정 기준 (절대 성과 아님):
  1. **비용 민감도** — 비용 0에서만 살고 현실 비용에서 죽으면 엣지 아님
  2. **임계값 안정성** — θ를 흔들어도 버티나
  3. **국면 간 일관성** — 여러 국면 넘나들며 유지되나

## 12. 전체 데이터 흐름

```
캔들 OHLCV (15m/1h/4h/1d)
  │
  ▼ [1층 신호처리 — 병렬]
  ├─ robust KF ──────→ slope + 불확실성   (팻테일 방어)   [계열1 추세]
  ├─ ER, Hurst ──────→ 레짐                              [계열2 레짐]
  ├─ 변동성 변화 ─────→ 수축팽창                          [계열3 변동성]
  ├─ 상대거래량 ──────→ 신뢰도                            [계열4 거래량]
  ├─ semi-deviation ─→ 꼬리위험         (팻테일 측정)     [계열5 분포]
  └─ 종가위치 ────────→ 봉 압력                           [계열6 형태]
  │   (전부 인과·상대량, z-score는 train 통계만)
  │
  ▼ (+ 멀티타임프레임 상위 맥락: 4h·1d 추세·레짐, 완성 봉만)
피처 벡터 (현재값 중심, 래그 0 시작)
  │
  ▼ [2층 공유트렁크 멀티태스크 MLP]
  ├─→ 배리어 결과 헤드 → softmax (상단/하단/만료 확률)
  └─→ 도달시간 헤드 → 분위수 (도달시간 분포)
  │   + 불확실성 (softmax + KF 공분산)
  │
  ▼ [3층 결정층]
  ├─ 멍청한 룰 (정찰): 방향·진입θ·고정사이즈·배리어청산 → 비용차감 손익
  └─ 최종 형태 (엣지 확인 후 결정)
  │
  ▼
매매 커맨드 (진입·방향·사이즈·청산)
```

**라벨 생성 (오프라인, 학습 데이터 준비):**
```
과거 캔들 → 변동성(ATR/YZ)으로 배리어 폭(x·N) 설정
         → 캔들 고저가 경로로 "어느 배리어 언제 도달" 판정
         → 배리어 결과 라벨 + 도달시간 라벨
         (전부 그 시점까지 정보만 — 인과성)
```

## 핵심 통찰 — 이 설계의 척추

**"1층에서 피처를 정성껏 가공한다"는 결정 하나가 하류를 다 단순하게 만들었다:**
- 시간 구조를 피처로 압축 → 2층이 MLP·벡터·래그0로 단순
- 대부분 상대량 → 정상성 자동 해결 (분수차분 불필요)
- 6축 독립 중복 제거 → 창 순차 탐색 정당화, KF와 semi-dev 상보성

**"무가정·인과성·장식금지"가 매 결정을 임의 선택이 아니라 제약에서 도출되게 만들었다.**

> 이것은 **검증된 시스템이 아니라 잘 설계된 가설**이다.
> 진짜 시험은 — 2층이 트리 벤치마크를 넘느냐, 멍청한 3층이 비용 넘겨 돈이 되느냐.
